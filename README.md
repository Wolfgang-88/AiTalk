# AiTalk

## English

AiTalk is a chat program for Windows that lets you talk to an AI via OpenRouter.

- Dark window with the output field at the top and the input field at the bottom
- API key, AI model, language (German/English) and answer format (Markdown/Text) under **Options**
- The OpenRouter guide (getting an API key and entering a model) is located in the installation folder
- Markdown display with tables, Python syntax colors and a copy button in code blocks
- Send files (`.py`, `.txt`, `.md`) to the AI by drag & drop
- Save files sent by the AI, save the chat history as Markdown and load it again


## Deutsch

AiTalk ist ein Chat-Programm für Windows, mit dem du dich über OpenRouter mit einer KI unterhalten kannst.

- Dunkles Fenster mit Ausgabefeld oben und Eingabefeld unten
- API-Key, KI-Modell, Sprache (Deutsch/English) und Antwortformat (Markdown/Text) unter **Optionen**
- Die OpenRouter-Anleitung (API-Key holen und Modell eintragen) liegt im Installationsordner
- Markdown-Darstellung mit Tabellen, Python-Syntaxfarben und Kopieren-Button in Code-Blöcken
- Dateien (`.py`, `.txt`, `.md`) per Drag & Drop an die KI senden
- Dateien der KI speichern, Chatverlauf als Markdown speichern und wieder laden
